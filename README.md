# Rolligan

A push-your-luck dice party game for groups of 2–10 players. Roll the dice, build the pot, bank your points before someone rolls a 7.

Built with Vite + React. Deployed on Vercel.

© 2026 Clarendon Labs LLC

## Local dev

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Host mode (Android app)

`/host` is banker mode: the same engine as the iOS app, ported to plain JS in
`src/engine/` (`GameState.js`, `GameConfig.js`, `Player.js`, `dice.js`), hosting a
room over Supabase Realtime broadcast exactly per `rolligan-ios/MULTIPLAYER.md`
(`RoomHost.js` / `RoomState.js`), so iOS and web joiners work unchanged. `/play` is
the app's start screen (web manifest `start_url`).

Hosting is only offered inside the Android app — `window.getDigitalGoodsService`
(Play Billing's Digital Goods API) is the switch; every ordinary browser stays
join-only. First 3 hosted games are free (`localStorage`), then Rolligan Pro
(`com.clarendonlabs.rolligan.host`, $2.99 once) via `src/billing/playBilling.js`
(Digital Goods API + Payment Request, restore via `listPurchases`). Entitlement is
client-side — there is no server to verify purchase tokens.

Local testing in a plain browser: `npm run dev`, open `/host?devhost=1` (dev builds
only; the flag is remembered in localStorage) and `/join?code=XXXX` in a second tab.

## Android (Google Play) — Trusted Web Activity

The Play Store app lives in `../rolligan-android` and is a Trusted Web Activity
around this site, generated by bubblewrap from `/manifest.webmanifest`
(`public/manifest.webmanifest`). Things on this side that it depends on:

- `public/.well-known/assetlinks.json` — Digital Asset Links for
  `com.clarendonlabs.rolligan`. Lists the upload key's SHA-256; add Play App
  Signing's certificate fingerprint after the first upload or the app shows a
  URL bar.
- `public/icon-192.png`, `public/icon-512.png` — manifest / launcher icons.
- `src/billing/playBilling.js` — Rolligan Pro through Google Play Billing inside
  the TWA. Create the in-app product `com.clarendonlabs.rolligan.host`
  (one-time, $2.99, "Rolligan Pro") in Play Console.
